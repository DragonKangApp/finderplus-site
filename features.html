FINDER+ / FEATURES

A useful menu. A considered workflow.

Explore Finder+ 1.0.0 features and the limits of file transfers.

Everyday file actions

01

Create & copy

New File: Plain Text, Markdown, JSON, XML and Swift, with existing template settings. Copy Path, Filename, File URL and Relative Path.

02

Open where you work

Open Terminal.app in the current folder, selected folder or file’s parent folder. Open With shows detected Xcode, VS Code and the default application.

03

Inspect & organize

SHA-256 hashes; legacy SHA-1 and MD5; logical Folder Size; Hide / Unhide; relative symbolic links and favorite destinations.

Transfers with an explicit choice

Copy and Move require authorization for both source and destination. Transfers run one at a time. Recent destinations refer to authorized roots; Favorites do not grant access.

01

Replace

Replace the entire target item after confirmation. Replacing a folder does not merge its contents. Some type mismatches and root symbolic links cannot be replaced.

02

Keep Both

Keep the original target and create another named copy. Review the final results for completed, skipped, failed and remaining items.

03

Skip

Keep the existing target. Skipping a Move also keeps its source. Apply to All applies only to the current task; the next task asks again.

History & recovery

Review active, recent and interrupted transfers. Inspect available locations before choosing a restore or cleanup action. Retry as New creates a new request; unfinished actions never replay automatically.

Restore Original, cleanup and a completed transfer describe different outcomes. Cleanup does not undo previously completed items. Cancel can briefly be unavailable during a safe commit or verified source cleanup.

History, recovery, restore, cleanup, cancellation and removal of folder authorization remain available regardless of trial or license status. Already accepted transfers are not interrupted by license changes.

Details that matter

  • Folder Size reports logical bytes, not physical disk usage, and does not follow symbolic links.
  • SHA-1 and MD5 are legacy options and should not be used for security verification.
  • Hide / Unhide changes the supported hidden attribute; it does not rename dotfiles to unhide them.
  • Terminal.app directory launch is validated. Other Terminal providers are not validated.
  • Finder context and extension coverage affect which actions are available.

Know your setup

Finder+ 1.0.0 is built for explicitly authorized local folders. These are the current release-candidate boundaries, rather than a promise of support on every Mac or disk.

macOS
14.0 minimum engineering target. Every macOS 14+ release has not been validated.
Apple Silicon
Validated on the development Mac. Final signed installation is still pending.
Intel
Compiled; runtime not validated.
Internal APFS
Supported, subject to folder permissions and capability checks.
APFS USB
Supported with limitations. Tested on one Kingston DataTraveler 3.0 device and one Mac; other devices and power-loss scenarios are not validated.
Internal HFS+
Runtime not validated.
exFAT / SMB / NFS / WebDAV
Copy and Move unsupported in 1.0.0.
File metadata
Full cloning is not guaranteed. ACLs, extended attributes, Finder tags and resource forks are not guaranteed; copied trees do not preserve hardlink relationships.
