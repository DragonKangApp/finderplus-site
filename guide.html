FINDER+ / GUIDE

A little guidance goes a long way.

A preview guide to Finder+ folders, actions, transfer choices and recovery.

Preview guide for the frozen 1.0.0 candidate. The App is not publicly available. Final installation instructions will accompany the signed release.

01 / Enable the Finder extension

Once a public release is available, open the main App, then choose Settings → Open Extension Settings. Find and enable Finder+ in macOS System Settings. The extension category depends on your macOS version.

Look for Finder+ under extensions; newer layouts may group it under File Providers, while macOS 14 may use Privacy & Security → Extensions → Finder Extensions. Reopen the Finder folder if needed.

02 / Choose your folders

In Authorized Folders, choose Add Folder… and select the specific folder you need through the system picker. Permission includes its subfolders, subject to macOS restrictions. Avoid granting an entire disk for convenience.

Remove revokes the saved permission without deleting files. Reauthorize asks you to choose the folder again. Favorites and recent destinations only reference authorized locations.

03 / Use the right-click menu

In a covered Finder location, right-click a file, folder or empty area and open Finder+. Some actions require a single selection or items in the same directory. An action is unavailable if the context cannot determine a suitable target.

New File creates a uniquely named file. Copy gives you paths, names or URLs. Open in Terminal uses Terminal.app. Utilities include hashes, logical folder size, supported hidden attributes and relative links.

04 / Copy or move with a decision

Authorize both source and destination, then choose Copy To or Move To. For an existing name, choose Replace, Keep Both or Skip. Folder Replace replaces the entire folder; it does not merge contents.

Apply to All affects the current task only. Cancel is available during cancellable stages and may briefly be disabled during a safe commit. Read the completed, failed, skipped and remaining results.

05 / Inspect interrupted work

Open Transfers → Needs Attention. Inspect source, target and retained data before selecting an available Restore or Cleanup action. Retry as New starts a new request. The App does not replay unfinished actions automatically.

A copied target does not by itself mean an entire Move succeeded. Cleanup does not undo completed items. Do not manually delete files whose recovery role is unclear.

06 / Connect an APFS USB carefully

Use an explicitly authorized subfolder on a supported APFS volume. A changed volume identity can require reauthorization even if its name and path look the same. Reconnect the original volume when it is unavailable.

Safely eject only after operations finish and attention items are resolved. Active-I/O unplugging and sudden power loss are not validated. Validation covers one Kingston device, not all USB devices.

07 / Trial & offline license

Choose Start Free Trial in License & Trial to start the 14-day timer. When licenses become available, use Import License to select the license file. Validation is local; an invalid import does not replace an existing valid license.

Remove Local License preserves files, permissions, history and recovery records. It restores the original trial’s remaining time or expired state. Already accepted transfers and all safety controls remain available.

Keep independent backups. Full metadata cloning is not guaranteed, exFAT and network transfers are unsupported, and Intel / internal HFS+ runtime remain unvalidated.
