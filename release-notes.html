FINDER+ / RELEASE NOTES

A frozen candidate. A release still ahead.

Finder+ 1.0.0 / build 3 candidate release notes. Not a public release.

Candidate notes · Finder+ 1.0.0 / build 3 · Not publicly released. No public release date has been announced.

Everyday Finder actions

Create Plain Text, Markdown, JSON, XML and Swift files. Copy paths, filenames, file URLs or relative paths. Open Terminal.app or detected installed applications from the Finder context menu.

Utilities & transfers

Hash, logical folder size, Hide / Unhide, relative symbolic links and Favorites. Copy / Move includes Replace, Keep Both, Skip and Apply to All for the current task.

Explicit folder authorization, recent authorized roots, transfer history and recovery controls. Folder Replace does not merge contents; unfinished work does not replay automatically.

Trial & license

Explicit 14-day trial, basic free mode afterward, and locally validated offline licenses. Build 3 includes production-license verification support. Payment and license delivery have not opened.

Safety controls and already accepted transfers remain available regardless of license changes.

Know your setup

Finder+ 1.0.0 is built for explicitly authorized local folders. These are the current release-candidate boundaries, rather than a promise of support on every Mac or disk.

macOS
14.0 minimum engineering target. Every macOS 14+ release has not been validated.
Apple Silicon
Validated on the development Mac. Final signed installation is still pending.
Intel
Compiled; runtime not validated.
Internal APFS
Supported, subject to folder permissions and capability checks.
APFS USB
Supported with limitations. Tested on one Kingston DataTraveler 3.0 device and one Mac; other devices and power-loss scenarios are not validated.
Internal HFS+
Runtime not validated.
exFAT / SMB / NFS / WebDAV
Copy and Move unsupported in 1.0.0.
File metadata
Full cloning is not guaranteed. ACLs, extended attributes, Finder tags and resource forks are not guaranteed; copied trees do not preserve hardlink relationships.

Release preparation

Developer ID signing, notarization, Gatekeeper verification and final signed installation checks are pending. Engineering readiness is not a public release or an invitation to install a development package.
