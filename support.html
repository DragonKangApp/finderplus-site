FINDER+ / SUPPORT

Keep the useful details. Keep private data private.

Finder+ pre-launch support status and a safe troubleshooting checklist.

Support submissions are not open. A verified contact will be published before sales begin. This website has no support form or mailing-list signup.

Start with the basics

  • Check that the main App has run once and the Finder extension is enabled.
  • Verify authorization for the specific source and target folders. Menu visibility does not grant content access.
  • Reconnect the original external volume; reauthorize if its identity changed.
  • Check the storage limits before attempting another transfer.

If a transfer needs attention

Stop starting affected transfers. Inspect the recorded result in Transfers → Needs Attention and check source and target. Use the normal recovery controls that are available for those locations.

Do not manually delete retained recovery files or treat a target copy as proof that every item in a Move completed. Recovery and history remain available without an active trial or license.

Prepare a useful report

When a support channel is available, include:

  • App version and build, macOS version, and Apple Silicon or Intel
  • Filesystem type and a brief description of the action
  • The error summary and whether operations remain unfinished
  • A minimal reproduction using non-private sample files, if possible

Omit file contents, full private paths, saved permission data, license contents or signatures, passwords and payment card details. Only share crash logs voluntarily after reviewing and redacting them.

Purchases & refunds

There is currently no purchase service. The selected provider, license delivery, refund policy and verified support channel will be confirmed before sales open. No support response-time or retention-period promise is made at this stage.
