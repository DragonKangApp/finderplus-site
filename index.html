Start a file where it belongs.

Create Plain Text, Markdown, JSON, XML or Swift files from the Finder menu. Name collisions create a new name rather than overwriting a file.

02

Take the useful details with you.

Copy a path, filename, file URL or relative path. Open Terminal.app in a folder or open items with a detected installed app.

03

Make the next move clear.

Copy or move between authorized folders. Choose Replace, Keep Both or Skip, then review the result in transfer history.

Your folders, your choice.

Access starts with a folder you choose.

Finder+ uses the system folder picker for content access. Menu visibility alone does not grant permission. Favorites are shortcuts, not permissions.

Interrupted work does not replay automatically. History and available recovery controls help you inspect the recorded result. Keep independent backups of important files.

Know your setup

Finder+ 1.0.0 is built for explicitly authorized local folders. These are the current release-candidate boundaries, rather than a promise of support on every Mac or disk.

macOS
14.0 minimum engineering target. Every macOS 14+ release has not been validated.
Apple Silicon
Validated on the development Mac. Final signed installation is still pending.
Intel
Compiled; runtime not validated.
Internal APFS
Supported, subject to folder permissions and capability checks.
APFS USB
Supported with limitations. Tested on one Kingston DataTraveler 3.0 device and one Mac; other devices and power-loss scenarios are not validated.
Internal HFS+
Runtime not validated.
exFAT / SMB / NFS / WebDAV
Copy and Move unsupported in 1.0.0.
File metadata
Full cloning is not guaranteed. ACLs, extended attributes, Finder tags and resource forks are not guaranteed; copied trees do not preserve hardlink relationships.
