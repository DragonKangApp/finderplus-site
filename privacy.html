FINDER+ / PRIVACY

Local work. Clear privacy notes.

Privacy notes for the frozen Finder+ candidate and this static website.

Scope of these notes

These notes describe the current Finder+ 1.0.0 / build 3 candidate and this pre-launch website. The final signed package and any future payment or support service need a separate review before launch.

Your files & folder permissions

Finder+ uses folders explicitly selected through the macOS folder picker for content operations. It does not require Full Disk Access. Finder can provide the extension with selected item names, paths and menu context; menu visibility is separate from permission to read or write contents.

Saved folder permissions, transfer history and recovery records remain on your Mac. History and recovery need local paths, operation state and relevant metadata. Removing permission does not delete your files or automatically erase recovery records.

The current App operates locally

The frozen App has no Finder+ account, cloud sync, file-upload service, analytics or automatic crash uploading. Its file operations and license validation run locally. Other apps you open, iCloud and third-party file providers may independently connect to the network.

Trial & license data

Trial timing and a local random identifier are stored in Keychain. The license is stored separately in the main App’s private application data and includes license identity, product/version terms, issue date, device allowance and a signature; it may include a display name.

There is no online activation, hardware fingerprint upload or online device counting in the current App. Folder permissions are separate from license data. Finder+ currently stores no payment data.

This website

This is a static information website. It has no analytics scripts, cookies set by site code, forms, account system, checkout or visitor storage. Fonts and visual assets are served with the website; there are no third-party font or tracking requests.

When hosted on GitHub Pages, GitHub logs visitors’ IP addresses for security purposes. That hosting behavior is separate from the local App. Read GitHub’s Pages data-collection notes and the GitHub Privacy Statement.

Before sales or support opens

No payment or support submission service is connected. A verified operator/contact, payment provider, relevant data uses and final terms will be published before those services open. Do not send private files, license contents or payment information through an unverified channel.

Notes prepared: 12 October 2026. Public availability has not begun.
